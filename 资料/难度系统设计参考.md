# DRG 难度系统设计参考（源自 Hazard X 自定义难度 Mod）

> 原文：Koncin（bilibili cv19376707），完整注释版存于 `资料/raw/自定义难度代码_HazardX注释版_Koncin.txt`
> 用途：这份配置把 DRG 的难度引擎参数全部暴露了出来，相当于官方难度设计的"数值策划表"。做我们自己的游戏时，可直接借鉴其**结构**和**数值尺度**。

## 一、DRG 难度引擎的三层预算体系（最重要的结构）

DRG 的难度不是拍脑袋刷怪，而是三套独立的"点数预算"在滚动：

1. **虫潮点数（EncounterDifficulty）**：每波虫潮分配一个点数预算（本配置 700–1800 点），从敌人池里按每个敌人的 `DifficultyRating` "购买"怪物直到预算花完。
2. **多样性预算（EnemyDiversity）**：同时 roll 本次包含的敌人**种类数**（22–30 种），防止池子单一。
3. **固定遭遇点数（StationaryDifficulty）**：开局洞穴里的静态威胁（水蛭、母巢、吐珠等）单独走一条预算（850–1050 点）。

> **可直接借鉴**：我们的游戏如果有关卡/事件生成，用"预算点数 + 单位点数价格 + 稀有度权重 + 种类数上限"这套四件套，复杂度和可调性都远好于固定波次表。

## 二、人数缩放系数表（1/2/3/4 人）

| 参数 | 1人 | 2人 | 3人 | 4人 |
|---|---|---|---|---|
| 普通敌人抗性 | 1.7 | 1.8 | 2.0 | 2.3 |
| 小型敌人抗性 | 1.2 | 1.2 | 1.2 | 1.2 |
| 无畏(BOSS)抗性 | 1.8 | 2.0 | 2.2 | 2.5 |
| 敌人伤害 × | 4.3 | 4.6 | 4.9 | 5.2 |
| 敌人数量 × | 1.35 | 1.55 | 1.95 | 2.6 |

要点：
- **伤害比数量增长更陡**（本配置伤害 4.3→5.2，数量 1.35→2.6），且不同体型的敌人抗性曲线不同——小怪恒定 1.2，大怪爬得更陡。多人不是简单翻倍，而是"数量、伤害、血量"三条曲线各自缩放。
- BOSS 抗性永远高于小怪，且 BOSS 曲线起步就高。

## 三、经济参数

- **补给价格**：60 硝石（1–4 人），5/6 人降为 55/50 —— 集体资源价格随队伍规模递减
- **开局资源**：硝石 40（不够叫一次补给，必须先挖）—— 强制"先投入后回报"的节奏
- **任务奖励系数（HazardBonus）**：1.33 —— 难度等级直接乘在收益上
- **友伤系数** 0.8、环境伤害 ×1.4

> **可直接借鉴**：这就是现成的运营经济杠杆——"消耗品定价随规模浮动、启动资金不足、难度与收益线性挂钩、失误惩罚打折"。

## 四、节奏参数

- 播报虫潮（大潮）间隔：120–180 秒（权重主投 7.5）
- 无宣告潮间隔：160–230 秒为主，穿插 200–260 秒
- 无宣告潮强度：1300–1700 点（不低！）
- 初始潮延迟：0 —— 开局就有压力
- 精英刷新冷却：0.1；场上精英上限：16

> 节奏是"双轨"的：**可预期的播报潮**（玩家能准备）+ **不可预期的静默潮**（防止蹲守）。间隔永远是一个区间而非定值。

## 五、变异与精英（随机性设计）

- 小怪变异率（战士→刀锋等）：主权重投 140–180%
- 禁卫→暴君：固定 32.5%
- 精英个体带独立抗性池（ExtraLarge…D），且 `Elite: true` 可叠加在特定敌人上
- 同类敌人有 `Rarity`（越大越少刷）、`Scale`（体型）、`TimeDilation`（时间流速，用于植物类）

## 六、单位描述符模板（EnemyDescriptors）

每个敌人可自定义的完整字段：
```
Base（原型）、DifficultyRating（点数）、Rarity（稀有度）、Scale（体型）、
IdealSpawnSize / Min / Max（刷怪量）、CreatureSize、TimeDilation（时间流速）、
Elite（是否精英）、SpawnAmountModifier、
CanBeUsedForConstantPressure（能否进虫潮）、CanBeUsedInEncounters（能否进遭遇）、
PawnStats（十系抗性：冰/腐蚀/电/爆炸/火/内伤/动能/物理/毒/辐射 + 移速 + 伤害抗性）
```
生物池分五类：公共 / 特殊 / 破坏性 / 开局固定 / 赛季事件，支持 add/remove。

## 七、护送单位（朵雷塔）独立减伤系统

- 玩家友伤 ×0.1、环境伤害 ×0.01、"大额伤害"减伤 95%（有触发阈值）—— 护送物的承伤走完全独立的三通道。

## 八、作者经验笔记 → 我们的设计规避清单

1. **数值有阈值**：点数/稀有度填离谱值（如 999）会直接无效 —— 我们做配置系统要 clamp 数值范围
2. **三套点数不等价**：刷潮点 ≠ 难度点 ≠ 稀有值点，不要混用一套单位
3. **"理想刷怪量=1"不代表只刷 1 只** —— 刷怪量要由预算系统+随机共同决定
4. **某些单位无法从池中移除，只能替换**（大螃蟹）—— 引擎要有兜底单位
5. **变异概率不为 0 时仍有保底产出**（典狱长照量产战士）—— 随机系统要有逻辑下限
6. StationaryEnemies 池加进去的单位开局就消耗固定点数 —— "开局即威胁"是预算预扣，不是免费白送

## 九、映射到我们的模拟运营游戏

| DRG 机制 | 我们的玩法映射建议 |
|---|---|
| 三层预算体系 | 关卡/商单/危机生成器：预算+单价+稀有度+多样性 |
| 人数缩放三曲线 | 难度等级（风险等级 1–5）对"成本/需求/竞争"分别缩放 |
| 60 硝石补给 / 开局 40 | 运营消耗品定价、启动资金紧张、先挖矿再消费 |
| HazardBonus 1.33 | 风险等级直接乘收益 |
| 播报潮+静默潮 | 可预期的大事件（提前通知）+ 随机小事件 |
| 变异率/精英 | 随机事件变异：普通订单→精英订单，概率表驱动 |
| PawnStats 十系抗性 | 如果做塔防/战斗元素：属性相克表 |
| 朵雷塔三通道减伤 | 重要资产（如钻机、基地设施）独立耐久系统 |

## 十、DRG 官方难度参照（背景知识）

官方风险等级 1–5（+6/7 模组扩展），官方配置下伤害/数量/血量同样随等级和人数缩放；这份 Hazard X 属于玩家自制的高难扩展（数值约为官方 5 级的数倍）。我们做难度曲线时建议以**官方 1–5 级的相对关系**为基准，Hazard X 数值作为"地狱难度"上限参考。

# 数值详情弹窗系统（B 设计 · 替代减字二期 tooltip 方案）

> 核心思路：主界面只留**图标+核心数字**，点任何数值/资源/卡片 → 弹出**结构化详情弹窗**。
> 比 tooltip 强：排版可控、手机友好、可以展示完整计算公式和来源分解。

---

## 一、通用详情弹窗组件

```js
/* A 一次实装，全游戏复用 */
function showDetail(title, rows) {
  /* rows = [{ icon:'', label:'当前产量', value:'×2.25' }, ...] */
  let html = '<h3>' + title + '</h3>';
  rows.forEach(r => {
    html += '<div class="drow">'
      + (r.icon ? '<img class="cicon" src="assets/icons/' + r.icon + '.png">' : '')
      + '<span class="dlabel">' + r.label + '</span>'
      + '<span class="dvalue">' + r.value + '</span></div>';
  });
  showModal(html); // 复用现有弹窗壳
}
```

```css
.drow{display:flex;align-items:center;gap:6px;padding:4px 0;border-bottom:1px solid var(--line);}
.dlabel{flex:1;color:var(--dim);font-size:12px;}
.dvalue{font-weight:bold;color:var(--amber);}
```

## 三、A 实装

1. `showDetail(title, rows)` 通用函数一次写好，全游戏复用
2. 各面板卡片加 `onclick → showDetail(...)` 传入结构化数据
3. 手机端：弹窗全屏 90vh，桌面端 520px 居中（复用 .modal .box 样式）
4. **主界面不再显示任何说明段落**——全部收进弹窗

| 交易站 | 每卡 5 行文字 | 每卡 3 行（图标+价格+按钮），点弹详情 | -50% |
| **总计** | — | — | **-60%** |

## 五、优先级

1. **P1**：通用 `showDetail()` 函数 + Header 资源 chip 点弹
2. **P1**：名册卡片点弹（合并 XP/任务/晋升/武器/饰品全部信息）
3. **P2**：任务板/交易站/深潜卡片点弹
4. **P3**：帮助页整合（被删的幽默文案集中展示）

## 一、系统总则

### 1.1 定位

精英支援位 = 后期养成顶点：从异动核心调来的 5 名**复拓者精英矮人**，作为第五~九类"编外战力"增援派遣。全部解锁后，每次派遣都可带一名对症的精英下场——"管理层手里的王牌"。

- **解锁前提**：钻井平台 **Lv10**（数值毕业门槛，B-1 §3.8）。
- **购买**：用**功绩点**（官方货币 Merit）逐个解锁，五人价格不同、能力不同，按需购入。
- **使用**：每次派遣**最多携带 1 名已解锁精英**增援（每任务每精英限一人，设计文档既定）；不占四职业满编的 4 个基线名额。
- **佩戴**：首版精英无独立装备（匠器接口预留，见 §五）。

### 1.2 与既有系统的咬合

| 系统 | 咬合点 |
|---|---|
| 深潜（B-4） | 功绩点最大产出源（10/周）；**建议**：深潜也可带 1 名精英增援（不破坏"四职业满编"基线，精英是第 5 人）——待拍板 §7 |
| 节日战役（B-5/A） | 战役里程碑建议产出数据节点/功绩点（与饰品链路图共用水池，A 对表） |
| 模组（B-3） | 精英不吃武器凭证（他们自带成装），避免与四职业抢养成线 |
| 事件（数值表 §二/§七） | 歼察员直接改写事件信息透明度，回溯者改写失败结算——五人各管一摊，不加新事件类型 |

## 二、五位精英总表（价格 = 功绩点，沿用 B-1 §3.8 建议值）

| 支援位 | 官方名 | 定位（原作） | 结算级效果（携带即生效，全队） | 价格 |
|---|---|---|---|---|
| 1 | **守护者** Guardian | 防御/坦克，震撼弹+排斥力场 | 全队医疗账单 **-30%**，重伤治疗时长 **-30%** | 20 |
| 2 | **歼察员** Spotter | 支援/标记，揭敌镖弹 | 事件弹窗**提前显示各选项成功率**，全事件检定 **+10%** | 30 |
| 3 | **驭鹰者** Falconer | 无人机侦察/电击无人机 | 稀有矿物掉落 **+15%**，富矿脉事件权重 **×1.5** | 30 |
| 4 | **切割者** Slicer | 近战，等离子能量剑+护盾腰带 | 虫潮/精英虫检定 **+25%**，战斗类失败惩罚（账单/士气减益）**减半** | 45 |
| 5 | **回溯者** Retcon | 治疗/回溯锚点 | 每周 **1 次回溯**：一次失败结算可整单回滚（重伤取消、账单免除、阶段进度保留） | 60 |

理由（逐人）：
- **守护者 20**：纯防御向入门款，账单 -30% 与医疗站升级线（满级 6 折）乘叠后"后期几乎免费受伤"，是最早买得起的保命位。
- **歼察员 30**：卖的是**信息**——本作事件二选一的核心是决策，把"盲选"变"明选"价值极高但不出数值，30 定价买体验。
- **驭鹰者 30**：稀有掉落 +15% 对齐饰品/模组的掉落档位，富矿 ×1.5 让"捞金周"有 explicitly 的 build 感。
- **切割者 45**：战斗特化，+25% 检定超过任何单模组（模组事件键最高 +20%）——最贵的进攻位，配合"硬刚流"。
- **回溯者 60**：唯一能改写结算的单位，每周限 1 次防滥用；对标 B-1"失败结算回滚"原案，是收藏者的毕业件。

五人合计 **185 功绩点**：功绩点来源 = 深潜 10/周（B-4）+ KPI 达成 5/季 + 危5 任务 1/次 + 精英虫猎杀 1/次 → 双轨深潜开启后约 **8-12 周**全收集，与模组全收集（≈10 周）、武器图鉴（2-3 月）同频收官。

## 三、机制细则

### 3.1 派遣规则

```
1. 派遣面板新增"精英增援"栏：显示已解锁精英，单选 0/1 名（默认不带）
2. 精英不占用四职业名额，不影响"人数-时长系数"（TimeFactor 按 4 人封顶计算）
   ——精英是超编战力，不改基础人力模型
3. 携带精英的派遣：补给硝石 +10/人口径不变（精英按 1 人计补给，营造"多一张嘴"的取舍）
4. 深潜：允许携带 1 名精英随队（建议值待拍板 §7-2）；带精英不豁免"重伤≥2 中止"规则
5. 精英自身不会重伤入院（复拓者有全套维生系统——风味豁免，简化结算）
```

### 3.2 结算顺序（给 A 的实装口径）

```
结算管线 = 基础公式（数值表 §1.2） → 模组加成（B-3 七键） → 饰品加成（B-5 七键）
         → 精英加成（本文档 §二） → 事件检定（T/P 修正） → 医疗/账单（守护者减免、切割者减半、回溯者回滚）
回溯者优先级最高：若本任务触发回溯，先回滚全部坏结果，再计入"本周回溯已用"
```

### 3.3 保存字段

```js
S.elite = { owned: ['guardian'],  carry: null | 'guardian',  rewindUsedThisWeek: false,  week: isoWeekKey() }
```

### 3.4 团灭救援（用户拍板 2026-09-13 新增）

- **团灭定义**：一次任务结算时，在场矿工**全部重伤入院**（含深潜阶段内全倒）。
- **救援**：存在**未随队**的已解锁精英时自动发动——已有产出按 **×50%** 保留带回（搜救归队）、全队账单 **-50%**、治疗时长 **-25%**，任务记为"搜救成功"；每次任务限 1 次，不消耗精英。
- 无可用精英（全在队/未解锁）→ 维持原失败流程。
- 理由：把"团灭"从纯惩罚变成精英系统的价值展示位；救回来的仍是伤员，与"全员可抢救"完全兼容。

## 五、匠器（一次性消耗品，用户拍板 2026-09-13 新增实装）

- **定位**：匠器 = 精英平时收集的一次性增益道具，使用后为**一个任务的全体矿工**提供增益，结算即消耗（原作匠器即"局内即拿即用"，本作做成一次性道具最贴原味）。
- **收集**：已解锁且**未随队**的精英自动外出收集——每名空闲精英每游戏日（=24 现实分钟）产出 1 个随机匠器，单精英库存上限 5 个。
- **使用**：派遣确认时可附加 **1 个**匠器（可不带），效果与模组/饰品**乘法叠加**，结算后消耗。
- 匠器池（7 个，官方名全部 locres 直证，效果为一次性）：

| 匠器 | 一次性效果 | 风味 |
|---|---|---|
| 玻璃大炮 Glass Cannon | 产出 +30%，医疗账单 +50% | 官方味的自杀式爆发 |
| 共生互利 Symbiotic | 医疗账单 -20%，全队士气 +3 | 互相补给，官方设定 |
| 固守堡垒 Bastion | 医疗账单 -30% | 稳如堡垒 |
| 连杀狂乱 Frenzy | 事件成功率 +15% | 越杀越上头 |
| 腺素助力 Adrenaline Booster | 任务时长 -15% | 跑得飞快，费得也快 |
| 元素大师 Elementalist | 主矿物产出 +20% | 火冰电三修，矿也服 |
| 战斗狂潮 Battle Frenzy | 战斗类事件检定 +20% | 打红眼的合规写法 |

理由：一次性 + 单任务限 1 个，数值敢给大（对标模组满档）但不可持续，不破坏长线平衡；收集挂"空闲精英"——想让匠器转得快，就得多买精英、少带他们下场，天然形成"养将 vs 用将"的取舍。

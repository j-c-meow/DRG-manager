# 挂机模式 + 重复员工补偿 + XP 曲线微调（B 设计 · 三合一施工单）

## 一、重复员工折算补偿（A 审计②，一行改法）

**结论：折算 300 代币。**

依据：招聘费 = 200~250×1.15^n，战役送的员工等于白嫖一次招聘，折半补偿合理。

```js
// rw.recruit 发放处加：
if(S.miners.some(m=>m.cls===cls)){ S.credits += 300; log('该职业已有员工，折算 300 代币。'); return; }
```

## 二、XP 曲线微调（A 审计③）

改两处数字：

| 项 | 旧 | 新 |
|---|---|---|
| XP 需求 | `mn.lv * 100` | `mn.lv * 60` |
| XP 获得（常规） | `20 * m.hazard` | `25 * m.hazard` |
| XP 获得（深潜） | `40 * m.hazard` | `50 * m.hazard` |

效果：Lv7 升级从 35 单→ **17 单**；Lv15 从 75→45。名册加 XP 进度条（复用士气条样式）。

## 三、挂机模式（A 审计④ + 用户点名）

**一个开关**（系统面板）：「挂机模式 ON/OFF」

ON 时自动执行：
1. 自动派遣：所有空闲矿工 → 自动接任务板最高报酬单
2. 自动事件：全部选稳妥项 B
3. 自动喝酒：士气 <30 → 自动请一轮最便宜的酒
4. 不加速不改速：用户手动选的倍速不变

OFF 恢复手动。关闭时如有自动派遣中的任务 → 不中断，跑完为止。

A 实装三步：
1. 系统面板加开关按钮
2. worldAdvance / tick 内：`if(S.auto.on)` → 自动匹配派遣 + 自动选事件 B 项 + 自动买酒
3. 事件弹窗在挂机模式下不弹（直接选 B 项记入日志）

# 减字二期施工单（B 设计 · 根治文字过多）

> 原则：**主界面零段落文字**——能图标的不用字，能数字的不用词，能折叠的不展开。
> 幽默文案不是删掉，是**藏进 tooltip**（hover/tap 显示）。

---

## 一、全局规则（所有面板通用）

| 规则 | 做法 |
|---|---|
| 面板标题 | 只保留 2-4 字标题（如"名册"），**删掉全部副标题/corporate幽默**（挪 tooltip 或帮助页） |
| 说明文字 | `class="note"` 的段落 → 默认 `display:none`，加一个 `?` 小按钮 hover/tap 显示 |
| 卡片描述 | `d.side` / `d.desc` 等 → 默认隐藏，卡片右上角加 `ⓘ` 图标 tap 展开 |
| 资源 chip | **删掉中文名**，只留图标+数字（`img` + `<b>` 已有，去掉文字标签） |
| 按钮文字 | ≤4 字（"派遣""升级""请一轮"已达标，继续守） |
| 日志 | 默认只显示最后 3 条，点标题展开全部；每行最多一行（`white-space:nowrap;overflow:hidden;text-overflow:ellipsis`） |

## 三、tooltip 系统（幽默文案的归宿）

```js
/* 减字 tooltip：所有被删的幽默文案存到 data-tip 属性，tap/hover 显示浮层 */
function bindTips(){
  document.querySelectorAll('[data-tip]').forEach(el=>{
    el.addEventListener('click', e => {
      e.stopPropagation();
      const tip = el.dataset.tip;
      if(!tip) return;
      // 简易浮层：跟随元素位置显示 2 秒后消失
      showTipPopup(tip);
    });
  });
}
```

- 每条被删的段落文字存到对应元素的 `data-tip` 属性
- 用户点 ?/ⓘ 图标或长按元素时弹出浮层显示
- 帮助页集中展示全部幽默文案（彩蛋回收）

| 名册 | ~400 字 | ~120 字 | -70% |
| 任务板 | ~600 字 | ~200 字 | -67% |
| 酒吧 | ~350 字 | ~100 字 | -71% |

| 装备终端 | ~500 字 | ~150 字 | -70% |
| 交易站 | ~400 字 | ~120 字 | -70% |

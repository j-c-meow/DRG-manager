## 一、总述与核心结论

**最重要的结论先行：两份官方本地化文本中，不存在名为 "Trinket" 的独立物品系统。**
全部 34,923 条文本中，无 `TrinketDescriptions` / `Trinkets` 之类的命名空间（两文件的 ns 列绝大多数为空，仅零星出现 SeasonalEvents / SeasonTexts / Schematics / UI / SeasonBriefings / NewStringTable / Resources 等），key 列（多为 MD5 哈希）与文本列中均无任何"饰品条目名 + 饰品描述"的成对结构。**去重后的"Trinket 饰品条目"数量 = 0。**

原作里玩家口中的"饰品/装饰配件"，官方文本体系实际对应 **Cosmetic（外观物品）系统**，官方中文翻译分两个口径：

| 文件 | 游戏 | Cosmetic 官方中文 |
|---|---|---|
| RC_文本全量 | 《深岩银河：Rogue Core》 | **"饰品"**（饰品箱、饰品链路图、"获取 {value} 件饰品"、"新饰品可用！"、"收集饰品"） |
| DRG_文本全量 | 《深岩银河》本体 | **"时装 / 时装物品"** 为主；少量固定词译作"饰品"（见下） |

DRG 本体中明确译作"饰品"的官方词只有 3 处来源：

| 英文 | 官方中文 | 出处 |
|---|---|---|
| Cosmetic Tree | **饰品链路图** | 赛季说明（2 条同文） |
| Cosmetic Sheet | **饰品链路图** | RC 文件（3 条） |
| Tree of Vanity（SeasonTexts） | **饰品链路图** | DRG |
| Season 06 Vanity | **第六赛季饰品** | DRG |
| Cosmetic Box / Cosmetics Box / Cosmetic Crate | **饰品箱** | RC（另 DRG 个别旧译"化妆品"，属低质量条目，见附录告警） |

**"Trinket" 一词在官方文本中仅出现 20 行，全部是节日活动"长髯物流货运船丢货"紧急 PSA**——玩家在任务中捡回掉落的节日装饰物换双倍绩效点数。此处 trinket 官方中文译为**"装饰物"**，是场景可拾取物，不是装备/栏位系统（详见第四节，可作"节日装饰物变体组"参考）。

## 二、官方"饰品体系"是什么（机制梳理）

原作的"饰品"= Cosmetic 体系，覆盖：头饰（Headwear/Hat）、护甲涂装、武器框架/皮肤、十字镐部件、胜利姿势、肤色、博斯科外观等。文本表只收录 UI 与说明文字，**具体每件饰品的名称不在这两份文本的可检索范围内以 "Trinket" 字样存在**（条目 key 为哈希，名字多以词条形式内嵌于奖励/商店文本）。可确认的官方机制文本：

- **RC《Rogue Core》**：地图内遇到 `<bold>Cosmetic Boxes</>（饰品箱）`——"绩效奖励系统的一部分，只有表现突出的高绩效员工可以获得特殊头饰"；开启后"内含一件适用于某一位**复拓者职业**的随机时装物品"；另有饰品链路图（Cosmetic Sheet）用**数据节点（Scrip）**购买推进。
- **DRG 本体**：饰品链路图（Cosmetic Tree）+ 数据节点（Scrip）；绩效通行证（Performance Pass）赛季等级奖励；矩阵核心锻造（时装物品矩阵核心 → 锻造台）；节日活动 Assignment 奖励头饰；时装商店（Accessory Shop）购买。

## 五、获取渠道线索（官方文本证据）

1. **深潜（Deep Dive）→ 矩阵核心 → 锻造饰品**（DRG，确凿）：
   "三提石钥匙能给你访问深潜终端的权限。你现在可以主持或加入**深潜**并获得**矩阵核心**，该物品可以用于锻造武器超频模组、**时装物品**和武器皮肤。"（"已灌注的时装物品矩阵核心 / Cosmetic Infused Matrix Core" + "+1 矩阵核心"是各类任务奖励固定项）
2. **节日活动 Assignment**（SeasonalEvents 命名空间，确凿）：复活节、夏日沙滩派对、啤酒节（含"狩猎巴伐利亚皮裤"）、万圣节、圣诞（含"狩猎圣诞小精灵"）、春节、春季任务，奖励均为"代币 + 矿石材料 + 已灌注时装物品矩阵核心 + 节日头饰"。
3. **赛季奖励**（确凿）：绩效通行证 Performance Pass 升级给"头饰、涂装、武器框架"；赛季回溯功能文本："曾属于赛季奖励的时装物品将被移回它们原先对应的绩效通行证或**饰品链路图**的位置"。
4. **饰品箱**（RC，确凿）：地图内开启，"内含一件适用于某一位复拓者职业的随机时装物品"；失败保底："如果任务失败，已在任务中获取的时装物品仍会保留。"
5. **饰品链路图 + 数据节点（Scrip）**（DRG+RC，确凿）。
6. **时装商店（Accessory Shop）**：购买 Accessory Items（"随着你的玩家等级提升，将会开放更多时装物品供你购买"）。
7. **DLC**（"新的时装扩展包！"等 5 条播报）。
8. **"Season 06 Vanity / 第六赛季饰品"**：官方把赛季外观合集直接称"饰品"的孤例。

## 七、对新"饰品加属性"系统的落地建议（基于官方文本）

1. **术语沿用官方口径**：物品大类叫"饰品"（RC 口径）完全站得住；"时装/时装物品"（DRG 口径）、"饰品链路图""饰品箱""数据节点"均可直接引用。
2. **稀有度梯度**可用官方词：少见（Uncommon）→ 稀有（Rare）→ 史诗（Epic）→ 传奇/传说（Legendary）。
3. **获取渠道文案风味**：管理层 PSA 通告体 + 绩效/HR 黑幽默（如饰品箱是"高绩效员工奖励系统"、丢失装饰物给"双倍绩效点数"）。
4. **节日饰品变体组**：第四节的 8 组节日装饰物（圣诞小精灵、新年龙龙、泳池玩具、春日兔兔、周年奖杯等）是现成的"同族多款式"素材。
5. **告警**：DRG 有低质量条目 `Cosmetics = 化妆品`（key ECB9EF8A…，两文件各有 1 条），文案引用时请避开。

# 手机分发指南（B 产出 · 面向不懂技术的群友）

> 用途：把《17号钻台》发给深岩银河群友玩。三个方案按"省事程度"排序，**方案一最推荐**（一次上传，人人有链接，手机电脑都能开）。
> 本游戏是纯网页（HTML+JS），不需要安装任何 App；存档在各人自己的浏览器里，换设备不互通。
> 配套素材：PWA 图标与启动画面已由会话 C 备好（`assets\pwa\`，含 manifest 接线代码），方案一/二上传时把 `assets` 整个带上即可支持"添加到主屏幕"。

---

## 方案一：Netlify Drop 免费托管（推荐，5 分钟搞定）

一次上传 = 得到一个永久链接，发群里谁点谁玩，手机电脑通吃。

1. 打开网站：`https://app.netlify.com/drop`（不用注册，直接能用；跳注册页就点右上角跳过/稍后）
2. 打开游戏文件夹（里面有 `游戏.html` 和 `assets` 文件夹的那层）
3. **把整个文件夹拖进网页中间的大框里**，松手
4. 等进度条走完（几秒到一分钟），网页上方出现一串链接，形如 `https://xxxxxxxx.netlify.app`
5. 点链接确认能玩 → 复制链接 → 甩进群里。完事。

**注意**：
- 拖的是**文件夹本身**，不是 zip 压缩包（如果是收到的 zip，先右键解压）
- 进游戏后如果只看到文件列表而没有游戏，说明拖的时候没包含 `游戏.html`（确认文件夹里直接有它）
- 免费版链接是随机的、永久有效；想换好记的名字要注册（免费）后改

## 方案二：GitHub Pages（备选，适合有 GitHub 账号的人）

1. 注册/登录 `github.com`，右上角 + → New repository，名字随意（如 `drg-idle`），选 Public，创建
2. 仓库页点 **uploading an existing file**，把游戏文件夹里的**全部文件**（`游戏.html` + 整个 `assets`）拖进去，点 Commit changes
3. 仓库页 Settings → 左侧 Pages → Branch 选 `main`，Save
4. 等 1-2 分钟，刷新页面顶部出现链接：`https://你的用户名.github.io/仓库名/游戏.html`
5. 这个链接发群即玩。以后更新游戏 = 重传同名文件覆盖。

## 方案三：局域网直连（同一家 WiFi 里最快的玩法）

电脑开个服务，手机浏览器直接访问电脑。**不联外网、不传第三方**，适合在家自用或局域网聚会。

1. 电脑按 `Win+R`，输入 `cmd` 回车，打开黑窗口
2. 粘贴这行并回车（假设游戏在 D 盘那个文件夹）：
   ```
   python -m http.server 8765 --directory D:\模拟运营小游戏
   ```
   （没装 Python 的话：微软商店搜 Python 安装，或用任意静态服务器工具）
3. 电脑查自己的 IP：按 `Win+R` 输入 `cmd` 回车，输入 `ipconfig` 回车，找"IPv4 地址"，形如 `192.168.2.19`
4. **手机连同一个 WiFi**，浏览器输入：`http://192.168.2.19:8765/游戏.html`（IP 换成你自己的）
5. 第一次弹"Windows 防火墙"提示要点**允许访问**；关闭黑窗口 = 停止服务

**常见问题**：手机打不开 → 九成是防火墙（重跑第 2 步时允许）或不在同一 WiFi；IP 打头必须是 `http://` 不是 `https://`。

## 手机打开之后（iOS / Android 通用说明）

- **横竖屏**：竖屏可玩，横屏更舒展（面板是响应式的，≤700px 自动切手机单列布局）
- **存档**：自动存在浏览器里；别用"无痕/隐私模式"玩（关了就没）；游戏内也有导出存档功能可备份
- **性能**：任何近几年的手机都带得动；老手机别开太多后台

## 添加到主屏幕（伪 App 模式，推荐）

游戏已支持 PWA（ Progressive Web App），添加后像原生 App 一样有图标、全屏启动：

- **iPhone（Safari）**：用 Safari 打开链接 → 底部分享按钮（方框+箭头）→ **添加到主屏幕** → 确认。图标和名字会出现在桌面
- **Android（Chrome）**：打开链接 → 右上角 ⋮ 菜单 → **添加到主屏幕** / **安装应用** → 确认
- 加完从桌面点开就是全屏游戏，没有浏览器地址栏，体验和 App 一致；存档独立于浏览器网页，更稳
- **微信里打开的注意**：群里的链接默认在微信内置浏览器打开，功能受限（不能添加到主屏幕、部分弹窗别扭）。正确姿势：点右上角 **⋯ → 在浏览器打开**，再用系统浏览器执行上面的添加步骤

## 三个方案怎么选（一句话）

| 场景 | 选哪个 |
|---|---|
| 发给整个群，长期可玩 | **方案一 Netlify**（或方案二） |
| 在家/局域网聚会，不想传外网 | 方案三 局域网 |
| 想要"像 App 一样点开就玩" | 任意方案 + 添加到主屏幕 |

# 日期与编年史系统设计（B-7 产出）

> 任务来源：用户拍板（2026-09-14 凌晨）——"开发个日期系统，照着 DRG 现实发售的日期往后一天天推，活动日期就有意义；按现实上线战役的时间同步；直到 2026 年 9 月 14 日游戏结束，变成无尽模式"。
> **一句话**：游戏内第 1 天 = DRG 正式发售日（2020-05-13），游戏日逐日对应现实日历一路推进；赛季、节日、周年庆全部落在历史上真实发生的位置；推进到 **2026-09-14**（今天）编年史收官，转**无尽模式**。
> 联动：节日战役档期（B-5 饰品）/ 战役解锁（A 的战役系统，替换 CAMP_DAYS 硬编码）/ 编年史 UI（新增）。

---

## 一、纪元与换算

### 1.1 纪元锚点（EPOCH）

**游戏第 1 天 = 2020-05-13（DRG 1.0 正式发售日）**。

- 日期是纯函数：`dateOf(gameDay) = 2020-05-13 + (gameDay - 1) 天`——不存档、不可逆推错，任何存档天然兼容（旧档 gameDay 直接获得日期，无需迁移）。
- `2026-09-14 = 第 2316 天`（2020-05-13 → 2026-09-14 共 2315 天间隔）。前 2316 天 = **编年史模式**（有剧本），之后 = **无尽模式**。
- 现实彩蛋锚点（一并入编年史，官方日期）：2016-02-25 抢先体验（EA）、2020-05-13 正式发售。游戏开局演出可打字幕："第 1 天。深岩银河集团刚刚敲钟上市——而你是它派往霍克斯星的最新一批管理层。"

### 1.2 流速与"赶进度"

- 自然流速：1:60 时钟下 **1 游戏日 = 24 现实分钟**（挂机/离线照常推进，离线上限 48h 内最多 +120 天）。
- 纯自然流速跑完 2316 天 ≈ 926 现实小时——**刻意设计为不可纯肝追平**，历史必须靠节点跳跃压缩：

**跳跃机制（赶进度的正当手段）**：
1. **完成一条战役队列 → 快进**到下一个编年史节点（演出一段"集团季度简报：本季度波澜不惊……"的过场 log，天数直接跳）。跳过的天数照常给离线式结算包（代币/矿物按日均折算），**节日与赛季节点不跳过**（必然亲自经历）。
2. **深潜通关不跳日**（周常与现实周绑定，本来就该一天天过）。
3. 三档跳日按钮（系统面板，可选，待拍板）：睡一天（+1 日，代价=当日无任务收益）/ 睡一周（+7 日，消耗 500 代币"集团休假申请"）——给不想看历史空窗的玩家自查自用。

- 节日循环完全复用 B-5 的档期表，但触发条件从"现实月份"改为"**编年史日期**"——因为游戏日=现实日，两者等价，而编年史版额外获得"历史次序感"（第一年的万圣节和第二年的万圣节是两场不同战役，掉落同系不同年的饰品变体）。
- 赛季战役十 queues（A 已做 10 条）恰好对应 1.0→S6 的十个内容节点，玩家每推进一个赛季 = 一条战役链 + 一批当期武器模组上新（与 B-3 的"武器靠战役解锁"完美咬合：S1 战役解锁 S1 时期的武器……）。
- 赛季精确日期标 ≈：官方发布会日期各记忆版本略有出入，不影响机制（节点只做解锁闸门，差几天无感知）；A 实装前可一次性核对（参考 B-3 已核实的 S6 转载页）。

## 三、无尽模式（第 2317 天起）

1. **终局战役「清账行动」**（还债制，原蓝图 ⑦）：编年史最后 30 天开启的巨型战役——把六年来所有"集团欠你的"（未领的绩效、被驳回的报销、每一次团灭的账单利息）打包成一张终极大单；完成 = 双向清账，编年史收官。
2. **无尽规则**：
   - 日期继续走（2026-09-15、16……），但不再有历史节点；节日按年度循环（同月份自动复发，饰品变体继续产出）。
   - 战役队列程序化生成：从十 queues 随机重组 + 难度按完成轮数 +8%/轮（软膨胀，用户已拍板"数值后期必然膨胀"）。
   - 深潜/酒吧/医疗/交易站照常——无尽模式不改任何基础循环。
   - 编年史 UI 变为**编年史·完**，可随时回看 2316 天的节点档案（纪念堂扩展位，纯展示无奖励）。
3. **荣誉结算**：收官时按编年史进度发一次性称号（文案键 ch_finale_title）：全员佩戴"历经全史"纪念饰品（镀金·周年奖杯，B-5 池内）。

## 四、JSON 配置（可直接嵌入 JS）

```js
/* 日期与编年史系统（B-7）——主会话负责实装；epoch 起 gameDay 即真实日期 */
const CHRONICLE = {
  epoch: "2020-05-13",                 // DRG 1.0 正式发售 = 游戏第 1 天
  finaleDate: "2026-09-14",            // 编年史终点 → 之后无尽
  dayRealMinutes: 24,                  // 1 游戏日 = 24 现实分钟（1:60 自然流速）
  jumpOnCampaignClear: true,           // 完成战役队列 → 快进至下一节点（节日/赛季不跳过）
  sleepButtons: { day1: true, week7: { cost: 500 } },   // 可选跳日（待拍板 §6-2）
  endless: { rotateFestivals: true, campaignDifficultyPerLoop: 1.08 },
  nodes: [
    { date:"2020-05-13", id:"launch",  name:"正式发售",        kind:"origin",  cert:"official" },
    { date:"2021-05-13", id:"anniv1",  name:"一周年",          kind:"anniv",   cert:"official" },
    { date:"2021-11-04", id:"s1",      name:"第一赛季",        kind:"season",  cert:"official" },
    { date:"2022-04-28", id:"s2",      name:"第二赛季",        kind:"season",  cert:"approx"  },
    { date:"2023-02-09", id:"s3",      name:"第三赛季",        kind:"season",  cert:"approx"  },
    { date:"2023-11-02", id:"s4",      name:"第四赛季",        kind:"season",  cert:"approx"  },
    { date:"2024-06-13", id:"s5",      name:"第五赛季",        kind:"season",  cert:"approx"  },
    { date:"2025-09-04", id:"s6",      name:"第六赛季",        kind:"season",  cert:"approx"  },
    { date:"2026-02-10", id:"lunar",   name:"春节（终场）",    kind:"festival",cert:"official-fest" },
    { date:"2026-09-14", id:"finale",  name:"清账行动",        kind:"finale",  cert:"user" }
  ]
};
/* dateOf(day): 以 epoch 为第 1 天的纯日期函数；
   nodeOf(date): 返回当前已越过的最后一个节点（解锁闸门）；
   isEndless(): dateOf(gameDay) > finaleDate */
```

> 节日（春节/复活节/啤酒节/万圣节/圣诞/夏日/周年）不入 nodes——它们是**按年循环的固定档期**（B-5 档期表已定义），编年史只管"历史事件"节点。B-5 饰品掉落改判据：编年史日期落在节日窗口内 → 当期节日战役开放。

# 手机端布局优化补丁（用户 09-16 四条点名 · C 出成品代码 · A 照贴）

> 用户四条：①任务板默认折叠，有员工没在干活才展开 ②派遣进行自动置顶+进度条做成矿道、对应职业小人在矿道里挖（挖到底=完成）③日志占屏减半 ④手机端 tab 菜单固定屏幕底部（像 App 底部导航）。
> 全部复用现有素材（dwarf_<cls>_dig.png 挖掘动画已有），零新增图片。规格对齐 700px 断点。

## ① 任务板：默认折叠 + 空闲矿工自动展开

现有 boardBtnSync 基础上加一条状态驱动（renderBoard() 开头插入）：

```js
/* 手机端：有空闲矿工=有单可接 → 自动展开任务板 */
if(isMobile() && FOLD.boardFolded && S.miners.some(m => m.state === 'idle')){
  FOLD.boardFolded = false;
}
```

放 renderBoard() 最前（boardBtnSync 之后已有的折叠逻辑不动）。效果：全员出差/住院=保持折叠省屏；一有人闲下来，任务板自动弹开提醒接单。

## ② 派遣通道：进行中置顶 + 矿道进度条（挖掘小人）

### CSS（style 区加）

```css
.dep .prog{position:relative;height:20px;background:#141019;border:1px solid #241c14;border-radius:2px;overflow:visible}
.dep .prog>i{background:repeating-linear-gradient(90deg,#3a2c1a 0 6px,#241c14 6px 12px);position:relative}
.dep .prog>i::after{content:'';position:absolute;inset:0;background:repeating-linear-gradient(90deg,rgba(87,215,196,.25) 0 4px,transparent 4px 12px)}
.dep .digger{position:absolute;bottom:-2px;width:24px;height:24px;image-rendering:pixelated;
  background-repeat:no-repeat;transform:translateX(-50%);z-index:2}
.dep-done .prog>i{background:var(--teal)}
```

### renderDeps() 改两处

a) **置顶**：渲染前按状态排序（进行中的在前，暂停事件的最前）：

```js
S.deps.forEach(d => { d._sort = (d.paused ? 0 : 1); });
S.deps.sort((a, b) => a._sort - b._sort || (a.start || 0) - (b.start || 0));
```
（放在 forEach 之前；不动 S.deps 本体顺序，用渲染副本排序——`[...S.deps].sort(...)` 更安全）

b) **矿道 + 挖掘小人**：进度条行替换为：

```js
const cls0 = d.minerIds.length ? (S.miners.find(m => m.id === d.minerIds[0]) || {}).cls : 'scout';
html += '<div class="prog"><i style="width:'+pct+'%"></i>'+
        '<span class="digger anim-spr" data-anim="dwarf_'+cls0+'_dig" style="left:'+pct+'%"></span></div>';
```

digger 复用 tickStages 驱动（.anim-spr 已有选择器），挖掘动画随进度自动横移，到 100% 即"挖穿矿道"=结算。
（tickStages 现有 scale 计算按 el 高度走，digger 24px 高会缩放 dig 帧 96→24，小而不糊，image-rendering:pixelated 保锐。）

## ④ 手机端底部 Tab 栏（固定屏幕底部，像 App 导航）

### CSS（700px 断点内）

```css
.tabs{position:fixed;bottom:0;left:0;right:0;z-index:40;margin:0;
  background:var(--panel);border-top:1px solid var(--line);
  overflow-x:auto;-webkit-overflow-scrolling:touch}
.tabs .tab{padding:12px 6px;min-width:60px;font-size:12px}
.tabs .tab.on{background:var(--panel2)}
body{padding-bottom:52px}   /* 给固定栏让位，防内容被盖 */
```

### 说明

- 现有 tab onclick 切换逻辑零改动——tabs 条只是从文档流里"拔出来"钉在屏幕底部
- 9 个 tab 横向可滚（现状），点哪个右侧面板显示哪个（现状逻辑）
- 可选增强：角标（医疗伤员数等，九项之⑤已做）在底部栏同样可见
- 桌面端不受影响（断点内生效）

## 验收点

- ①全员任务中→任务板自动折叠；有人 idle→自动弹开
- ②进行中派遣卡置顶；小人随进度横移且在挖（动画帧在动）；挖到最右端=结算触发
- ③手机端日志区高度≈96px
- ④底部栏固定不随滚动消失；点 tab 正常切换面板；页面底部内容不被盖（body padding-bottom）

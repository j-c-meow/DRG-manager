# 减字专项方案（前端优化二期 · 会话 C 主导 · 2026-09-14）

> 依据：用户第二轮反馈第 1 条"最大问题=字太多密密麻麻"（A 下达，C 主导）。
> **实物 mockup：`assets\anim\preview.html` "减字专项 mockup"区**（任务卡两级/战役行一行/日志折叠/帮助页四个演示，含点击展开交互，CSS 直接抄）。

## 一、总原则（一句话）

**卡片最多两行字**：主行（名字/危险度）+ 副行（图标+数字）；条款、规则、说明等一切三级信息 → 点击折叠 或 挪帮助页。

## 二、六条规则与实装映射（A 按此改 游戏.html）

| # | 规则 | 实装点 | 做法 |
|---|---|---|---|
| 1 | 任务卡两级：默认=横幅+名+危徽章+矿物 chip+派遣按钮；**条款/深度档/建议职业 → "详情 ▸"点击展开** | `renderBoard()` | 详情包进 `.det`（display:none 切换），简洁模式维持现状 |
| 2 | 战役/编年史/节日三行合一：`D455 2176-08-12 ｜ 万圣惊魂夜 1/2 ｜ 详情▸` | `renderCampaign()` | campbar 压成单行 flex；播报文字进"详情"展开 |
| 3 | 日志默认只渲染最近 5 条+警报常驻；例行 sys 行合并为"……例行 N 条（点击展开）" | `log()` / renderLog | 例行行存数组，点开一次性插入；"放大"弹窗维持全量 |
| 4 | 长文挪帮助页：系统页加"📖 玩法帮助"弹窗，承接名册晋升阶梯长文/士气规则/条款说明/离线说明 | renderSys() + showModal | 名册底部约 120 字长文删除，卡片只留一句"详见玩法帮助" |
| 5 | 数值图标化：剩余时间/账单/XP 等一律"图标+数字"，不写全称 | 各 render | ⏱ 时间、◈ 代币、＋红棉花/矿物沿用 icons |
| 6 | 文字层级：主行 13px 亮色 / 副行 11px dim / 三级折叠，禁止三级同屏 | 全局 | 沿用 .note/.meta，新增 .det |

## 三、验收点

- 任意任务卡正文 ≤2 行 + chips 一行；条款零默认展示
- campbar 一行（375px 宽不折行，超长省略号）
- 日志默认可见 ≤5 条；警报/结算行永不折叠
- 名册底部无长文（挪帮助页后）
- 所有折叠内容 1 次点击可达；375px 无横向溢出

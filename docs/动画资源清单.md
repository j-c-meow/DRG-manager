```js
/* 头像框：静态 <img>，仅在 renderRoster 里按状态换 src（无逐帧逻辑，永不闪） */
function avatarHtml(cls, state){
  const p = 'assets/anim/portrait_' + cls + (state==='med' ? '_med' : '') + '.png';
  return '<div class="avat' + (state==='mission'?' mission':state==='med'?' med':'') +
         '"><img src="'+p+'" alt=""></div>';
}
/* 动画展示位：全局时钟逐帧（innerHTML 重渲染不重启）；每帧调 */
function tickStages(now){
  document.querySelectorAll('.dstage .spr').forEach(el=>{
    const a = ANIM[el.dataset.anim]; if(!a) return;
    const f = Math.floor(now/1000*a.fps) % a.frames;
    const s = 72 / a.frameH;
    el.style.backgroundImage = 'url('+a.src+')';
    el.style.backgroundSize = (a.frameW*a.frames*s)+'px '+(a.frameH*s)+'px';
    el.style.backgroundPosition = (-f*a.frameW*s)+'px 0';
  });
}
```
`renderRoster()` 模板：行首插 `avatarHtml(m.cls, m.state)`，卡片底部（士气条上方）插 `<div class="dstage"><div class="spr" data-anim="dwarf_'+m.cls+'_'+(m.state==='mission'?'walk':m.state==='med'?'med':'idle')+'"></div></div>`。信息密度建议：XP/任务次数/晋升加成合并为一行 `.note` 小字，卡片立刻疏朗。

## 5. 规格铁律

- 只用 PNG 精灵图 + JS 帧数据；禁止外部库/GIF/视频/音频；游戏端 `image-rendering:pixelated`。
- 逻辑网格 ×3 最近邻导出；单文件 ≤200KB、总量 ≤3MB。
- 造型规范：**不用纯黑描边**——同色系暗部塑体积 + 外圈极暗蓝灰(18,20,24) 勾剪影；配色采样官方素材。
- 文件名英文小写+下划线；显示名一律官方译名（朵蕾妲非"朵雷塔"，`游戏.html:874` 待 A 更正）。
- 雷区：任何产出不得提及交接文档第二节所列的违禁用户（名字只允许存在于交接文档规则区，各交付文档一律 0 提及——本行已由会话B两次清扫，请勿再写回具体名字）。

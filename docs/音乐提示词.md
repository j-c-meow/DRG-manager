# Suno 游戏进行 BGM 提示词（会话 C 供 · 无歌词 · 只需风格）

> 用途：游戏进行时循环播放的背景音乐。全部 Instrumental（无歌词）。
> 用法：Suno Custom 模式，把 Style 整段粘进风格栏，开 Instrumental，每版出 2-3 个挑最耐听的。
> 验收标准：能循环听 20 分钟不烦、不打断阅读（游戏是文字管理界面，音乐是垫底不是主角）。

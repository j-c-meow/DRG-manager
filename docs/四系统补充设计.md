## 二、纪念堂 / 收藏图鉴

### 设计
- **入口**：装备终端新增「纪念堂」按钮（官方名词）
- **展示**：四个 tab——
  1. **编年史档案**：2316 天时间线（已过节点高亮，未到灰色），点节点看当日事件日志汇总
  2. **武器图鉴**：24 把武器卡片（已解锁彩色/未解锁灰+锁），显示升级等级+模组
  3. **饰品陈列柜**：已收集饰品按系列排（节日/时装/镀金），未收集显示剪影+获取方式
  4. **成就墙**：40 项成就按五组排，已解锁金色框

### 数据
```js
S.collection = { weapons:{}, trinkets:{}, achievements:{}, chronicle:{} };
```

### A 实装
- 纯展示 UI，无新逻辑——读已有数据渲染四 tab
- C 可出纪念堂背景像素画

## 三、自定义难度终端

### 设计（原型蓝图 ⑧ + 难度系统设计参考）

**入口**：系统面板新增「自定义难度终端」按钮

**可调参数**（改动即生效，存档保存）：
| 参数 | 范围 | 默认 |
|---|---|---|
| 危险系数倍率 | ×0.5 ~ ×3.0 | ×1.0 |
| 硝石消耗倍率 | ×0.5 ~ ×3.0 | ×1.0 |
| 事件频率倍率 | ×0.5 ~ ×3.0 | ×1.0 |
| 士气衰减倍率 | ×0.5 ~ ×2.0 | ×1.0 |
| 产出倍率 | ×0.5 ~ ×3.0 | ×1.0 |
| 市场波动倍率 | ×0.5 ~ ×2.0 | ×1.0 |

**预设**：原作五档快捷键（危1~危5 一键套参数）+ 自定义微调

**奖励系数**：难度越高，全部产出 ×对应倍率（自我平衡，不做额外奖励）

### A 实装
- 系统面板加按钮 → 弹窗显示滑条组 → 确认后写入 `S.difficulty` 对象
- 全部结算公式乘以 `S.difficulty` 对应倍率

## 四、矿骡升级线

### 设计
- 矿骡（M.U.L.E.）目前只是搬运工，升级后获得额外功能
- **升级线**（3 级，吃玉石+乌玛石）：

| 级 | 升级费 | 新功能 |
|---|---|---|
| Lv1（初始） | — | 基础运输（现状） |
| Lv2 | 玉石×30 + 乌玛石×30 | 自动收集：任务结算时自动拾取 50% 遗漏矿物 |
| Lv3 | 玉石×60 + 乌玛石×60 + 蜂母石×30 | 超载运输：每次派遣额外携带 +50% 硝石上限 |

### JSON
```js
const MULE_UPGRADES = [
  { lv:2, cost:{玉石:30, 乌玛石:30}, effect:"auto_collect_50" },
  { lv:3, cost:{玉石:60, 乌玛石:60, 蜂母石:30}, effect:"nitra_cap_plus_50" },
];
```

## 五、优先级建议

| 优先级 | 系统 | 理由 |
|---|---|---|
| **P1** | 成就系统 | 40 项全用已有数据判定，A 改动最小、玩家感知最大 |
| **P1** | 矿骡升级线 | 3 级 JSON 一个常量，代码量最小 |
| **P2** | 纪念堂/图鉴 | 纯展示 UI，等全部内容稳定后再做 |
| **P2** | 自定义难度终端 | 滑条 UI 工作量中等，等核心平衡调完再做 |

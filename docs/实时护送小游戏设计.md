# 实时护送小游戏（推车任务）设计 · 2026-09-19

> 依据：locres 官方语料（DRG_文本全量_en_zh.tsv）+ pak 资源检索。基于现有实时采矿引擎（src/realtime/*）扩展，任务类型 `escort`（执勤护送）。

## 官方流程锚点（locres 原文）
1. 「朵蕾妲开路！保持警惕，就像她是你们的亲妈一样保护好她！」——朵蕾妲（Doretta，掘进机）自动向前掘进，玩家护送。
2. 「Doretta is under attack! 朵蕾妲在遭受攻击！」——虫咬朵蕾妲掉血，需杀虫保护。
3. 燃料罐循环：「Canister ready for re-fueling! 燃料罐已准备好重新供油！」→「Canister placed! 燃料罐已放置！」→「所有燃料罐已装满！掘进机已准备好继续执行任务！」——停车取罐加油后恢复推进。
4. 「朵蕾妲这样撑不下去的！」——血量危急警告；血尽=任务失败。
5. 终点：「完成！奥魔兰心石，我们来了！」——心石阶段防守后撤离=胜利。

## 小游戏化设计
- **关卡**：横向长廊（复用洞穴生成，改为单向长通道+3 处加宽据点），朵蕾妲沿底部轨道自动向右推进（基础速度恒定）。
- **朵蕾妲实体**：血条（100），被近战虫啃咬掉血；血<30% 触发危急台词与红色警示；血尽=失败。素材：pak `FSD/Content/Art/UI/HUD_Radar_Icon_Drilldozer.uasset`（2D 雷达图标，umodel 导出→放大像素化处理），备用 fallback=mission_escort.png。
- **燃料检查点**：进度 50% / 100% 两处：朵蕾妲停车，身旁刷油罐拾取物；玩家走近按 E 拾起（头顶携带标记），再走近朵蕾妲油箱口按 E 加入——两段交互，都在朵蕾妲身上完成（拿罐+加油即"在朵蕾妲身上拿出油罐加一次油"的两次检查点实现）。加油完成→恢复推进+台词。
- **虫潮**：25%/50%/75% 进度各一波 swarm + 随机零散爬虫；虫优先咬朵蕾妲，其次攻击玩家（复用现有敌人 AI/伤害）。
- **心石防守**：100% 加油完成后到达终点，倒计时 20 秒防守（连续两波），倒计时结束=WIN。
- **玩家**：复用现有移动/挖掘忽略/射击/倒地 BOSCO 救援；照明弹照常。
- **HUD**：顶部新增朵蕾妲进度轨（车头位置 0→100% + 血条 + 燃料状态图标），复用现有 HUD 框架。
- **结算**：WIN → integration.complete(mission, true…) 走现有 settle；朵蕾妲血尽 → complete(…, false…) 走失败。**介入模式复用**：执勤护送类型的派遣卡同样出现「⚡实时介入」按钮（含 board 卡实时下矿按钮放开 escort 类型）， nitraSpent=0、冻结/恢复语义与采矿介入一致。

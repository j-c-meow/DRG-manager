# 手机端显示修复单（B 诊断 · 给 A 的施工单）

> 依据：用户手机实测截图（http://drg.manager.mintcat.work/，2026-09-13 20:21）+ 部署版 HTML 逐段诊断。
> 部署版基本是最新构建（viewport meta ✓ / 700px 断点 ✓ / MEME_EVENTS 单声明 ✓），问题出在**移动端适配的三处 CSS/渲染 bug**。

---

## 修 1：稀有矿物重复渲染（截图实锤：两行"稀有矿物"）

**位置**：renderHeader 尾部（`稀有矿物（点击展开）` 字样处）。

**根因**：折叠态下先渲染了带 ▼ 的折叠框（fold-head 本身就是开关），**然后又追加了一枚独立的"▸ 稀有矿物（点击展开）"chip**——两个开关叠在一起。

**修法**：删掉这段三元追加（fold-head 已可点击，冗余）：
```js
// 删除这一段：
(FOLD.rares ? '<span class="chip note" style="cursor:pointer;" data-fold="rares">▸ 稀有矿物（点击展开）</span>' : '')
```

## 修 2：任务卡产出被裁切（截图实锤："黄金×…" 半截消失）

**根因**：全局 `.chip{white-space:nowrap}` + `.mcard{overflow:hidden}` 的组合——产出行里的"黄金×N"chip 排到行尾时既不换行也不收缩，直接被卡片裁掉。

**修法**（在 @media(max-width:700px) 断点内追加）：
```css
.mcard .chip{white-space:normal;}
.mcard div{flex-wrap:wrap;}
```
（第一条允许 chip 内换行；第二条确保卡片内所有 flex 行可换行。桌面端不受影响——只在 700px 断点生效。）

## 修 3：移动端卡片密度与观感（"显示不大好"的主观感受主要来源）

**现状**：700px 断点只缩了字号和按钮，卡片排版还是桌面思路，一屏一卡、按钮巨大。

**修法**（断点内追加）：
```css
.mcard{padding:8px;}
.mcard .btn{padding:10px 0; font-size:14px;}
.mcard .note{font-size:11px;}
h3.sec{font-size:14px; margin:10px 0 6px;}
```

## 修 4（可选）：手机端稀有矿物默认展开

折叠是为了省空间，但手机上多一次点击才看到关键资源。建议窄屏时 `FOLD.rares` 初始为 false（`window.innerWidth<=700` 时不折叠）。

## 修 5（必做）：微信内打开的提示

用户截图来自**微信内置浏览器**（顶栏有关闭 X）。微信 webview：①PWA"添加到主屏幕"不可用 ②部分弹窗交互受限。建议：
- 检测到微信 UA 时，页面顶部加一条提示条："微信内体验受限，点右上角 ⋯ → 在浏览器打开，体验更佳"

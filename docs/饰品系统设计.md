# 饰品系统设计（B-5 产出）

> 任务代号 B-5（收发箱 2026-09-13，用户点名）。
> **核心设定（用户拍板）**：原作饰品（Cosmetic/时装）纯外观、不能加属性；本作模拟运营化——**饰品加属性**，成为与武器模组并列的第二条装备养成线。
> **范围界定（用户拍板 2026-09-13，最高优先级）**：异动核心的**匠器（Artifacts）不属于饰品**——匠器预留给未来的**精英矮人增援系统**（异动核心五职业，未设计）。本系统的素材来源**只取 DRG 本体侧**（时装/装饰/节日体系，官方名全部现成）；RC 装饰类（面部饰品 HeadAccessory 等）同样预留不进首版池。
> **素材依据**：`资料\饰品_文本调研.md`（192 行官方文本命中）+ `资料\饰品_pak调研.md`（两 pak 全量清点）；所有物品名均为官方译名（3 个直译名已标注"待核"）。
> **数值口径**：效果沿用 B-3 七键体系（yield/duration/eventSuccess/rareDrop/morale/supplyCost/medBill）；稀有度用官方词 少见/稀有/史诗/传说。

## 一、系统总则

### 1.1 定位与铁律

- **饰品 = 佩戴型属性配件**：原作纯外观 → 本作加属性，与武器模组（大数值、绑武器、抽卡获取）形成层次差：饰品是小数值、绑矿工、多渠道掉落。
- **佩戴**：每名矿工 **1 个饰品槽**（官方栏位词：**面部饰品 Head Accessory**）；4 矿工满编最多 4 件生效。
- **生效规则**：效果为**全队结算加成**（佩戴于任一在队矿工即生效）；同名饰品不可重复佩戴、不叠加。
- **卸下/更换**：装新卸旧，旧饰品回仓库，可换给其他矿工。
- 全员可抢救铁律照旧：饰品没有"损坏/丢失"机制，最坏情况只是不装。

### 1.2 稀有度四档（官方词）与数值锚

| 稀有度（官方词） | 数值档 | 典型形态 |
|---|---|---|
| 少见 Uncommon | 单键 ±5%（士气类 ±2） | 时装系基础款 |
| 稀有 Rare | 单键 ±10%（士气类 ±4） | 时装系进阶 / 节日装饰物 |
| 史诗 Epic | 单键 +15% 或双键 +10%/+5% | 节日头饰 / 周年奖杯 |
| 传说 Legendary | 双键 +20%/+10% 或单键 +25%（可带 -2 士气小代价） | 镀金节日饰品（深潜末关限定） |

理由：数值锚对齐模组体系的量级（模组单键最高 +35%、双键常见）——饰品整体半档于模组，避免两条装备线互相碾压；四档词全部为 DRG/RC 官方文本原词（Rare COSMETICS=稀有时装物品 等原文直证）。

### 1.3 获取渠道（三系统串联，用户拍板的核心结构）

| 渠道 | 掉落 | 联动 |
|---|---|---|
| **深潜第三关（末关）通关** | 普通深潜：当季节日饰品 ×1（10% 概率**镀金版**=传说档）；精英深潜：必掉镀金版或周年奖杯系 | 对齐原作"深潜末关给饰品"（原作为矩阵核心→锻造时装，本作直接掉饰品，更爽快）；与 B-4 深潜双轨绑定 |
| **节日战役**（挂 A 的战役系统） | 当季节日限定饰品 ×1 + 节日头饰（史诗） | 按现实月份开放对应节日战役（档期表见 §4） |
| **三提石任务** | 附带 25% 概率掉**饰品箱**（官方词）→ 开出时装系随机款（少见/稀有） | 挂 B-3 模组抽卡的既有任务钩子，不加新任务类型 |
| **饰品链路图**（官方词：Cosmetic Tree） | 固定节点解锁时装系指定款 | 消耗**数据节点 Scrip**（官方词）——产出挂 KPI 达成与战役里程碑，数值待拍板 §7 |

理由：四个渠道全部有原作机制对应（深潜矩阵核心/节日 Assignment/饰品箱/饰品链路图+数据节点，文本调研第五节均有原文直证），玩家认知零成本；三系统串联 = 深潜给毕业饰、节日战役给限定饰、日常抽卡给基础饰。
